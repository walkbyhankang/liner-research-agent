## 기업마당 지원사업정보 API

- 접수 가능한 공고 **1,303건**(마감 공고는 API가 주지 않음). 분야별: 경영 413, 금융 226, 기술 222, 인력 155, 수출 138, 내수 83, 창업 61, 기타 5.
- 분야 코드: 01 금융, 02 기술, 03 인력, 04 수출, 05 내수, 06 창업, 07 경영, 09 기타(08은 결과 없음).
- 금융 226건의 중분류: 융자 163, 보증 47, 보험(수출·무역) 14, 펀드/투자 2.
- 지원대상 분류: 중소기업 1,008, 소상공인 179, 창업벤처 77, 사회적기업 25, 장애인기업 7, 제조업 4, 여성기업 3.

### 한계
- **신청기간의 71%(923건)가 날짜가 아니다**: "예산 소진시까지" 645, "상시 접수" 137 등. 지금 접수하는지는 원문 확인이 필요하다.
- **세부 자격이 구조화돼 있지 않다**: 업력, 업종, 매출, 한도, 금리는 개요 문장이나 첨부 공고문에만 있다.
- **`hashtags` 검색은 OR 조건**이다("금융,대전" → 591건). 서버 필터에 의존하지 않고 전체를 받아 직접 거른다.
- **지역 분류가 불완전하다**: 지방자치단체 공고 978건 중 80건에 전 지역 태그가 붙어 있다. 실제 전국 대상인지 판단할 수 없어 화면에서 "다른 지역 기업도 신청할 수 있는지 확인"으로 표시한다.
- 문의처에 담당자 이메일이 들어 있어 스냅샷에서는 이메일을 지운다.

## 한국벤처투자 펀드현황 Open API

- 한국모태펀드 자펀드 **1,480개**. 만기 전 821개, 그중 한국벤처투자가 직접 운용하는 60개를 뺀 **761개(운용사 279곳)** 를 화면에 쓴다.
- 필드: `year`(결성 연도, "2025년" 형식), `fd`(출자분야), `mng`(운용사), `asn`(조합명), `exp`(만기일), `ca`(약정액), `amt`(금액).
- 출자분야는 만기 전 펀드 기준 186종의 자유 표기(창업초기, 청년창업, 초격차, 소재부품장비, 문화산업 등).

### 한계
- **`amt`는 전 건이 비어 있다.**
- **`ca`(약정액)의 단위와 기준이 문서에 없다.** 펀드 총액인지 모태펀드 출자 약정액인지 확인되지 않아 화면에 금액을 표시하지 않는다. 한국벤처투자에 확인이 필요하다.
- **2026년 결성 펀드가 없다**(최신 2025년). 갱신 주기는 확인하지 못했다.
- **신규 투자 집행 여부, 잔여 투자 재원, 기업당 투자금, 투자 실적, 연락처가 없다.**
- 모태펀드가 출자하지 않은 펀드는 포함되지 않는다.
