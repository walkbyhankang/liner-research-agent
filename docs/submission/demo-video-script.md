# 데모 영상 대본 (초안)

> 라이너 해커톤 제출용. 제한 5분, 목표 길이 **4분 30초**. 처음 작성 2026-11-21(펀딩노트), 성장노트 화면 흐름으로 고침 2026-11-23(가독성 개선·"지금 확인할 것"·동명 법인 구분 반영). 같은 날 화면 구조 개편 반영: 상단 메뉴 회사 분석 · 경쟁사 분석 · 자금·판로 · 심사 준비 · 노트, 경쟁사 장면 추가, 판로는 자금·판로 안으로.
> 시연 회사는 **기준 기업**(지금 법인)이다. 회사 분석은 서버에 저장해 둔 실제 분석("예시 회사")을 쓰고, 공고문 자격 대조 1건과 운용사 요약 1건은 촬영 중에 실제로 호출한다(**비용이 나간다**).
> 말하는 문장은 초안이다. 소요 시간은 이 저장소에서 실제로 잰 값이다.

## 영상이 전해야 할 세 가지

1. **문제**: 회사 자료는 흩어져 있고 자료끼리 다르기도 하다. 그 자료로 자금·심사·판로를 따로 준비해야 한다.
2. **해결**: 회사 이름 하나로 회사를 분석하고(값마다 상태와 출처), 국내 경쟁사와 나란히 본 뒤, 그 값으로 자금·판로 → 심사 준비 → 노트까지 잇는다. 모르는 것은 "미확보", 다른 것은 "엇갈림"으로 그대로 보여 준다.
3. **Liner API**: 검색은 Liner 검색·Premium·학술 검색, 판단은 Liner로 부른 모델, 그 결과는 코드가 원문과 대조한다.

## 촬영 전 준비

| 할 일 | 이유 |
|---|---|
| `.env`에 `LINER_API_KEY`, `DATA_GO_KR_SERVICE_KEY`, `NAVER_CLIENT_ID`·`NAVER_CLIENT_SECRET`이 있는지 확인 | 공고문 대조·운용사 요약(Liner), 회사 확정·판로(공공데이터포털)에 쓴다 |
| **예시 회사 설정**: 기준 기업 지금 법인의 분석이 끝까지 끝나 서버에 있는지 확인하고, 그 회사 id(법인등록번호 13자리, 회사 화면 주소 `/c/<id>`)를 `.env`의 `GROWTH_EXAMPLE_COMPANY_ID`에 적는다 | 저장된 분석이 있어야 "예시 회사로 보기"가 나온다. 분석 결과와 회사 id는 저장소에 넣지 않는다 |
| `scripts/run_local.sh` 실행 → `http://127.0.0.1:3100` | `.env`를 고쳤으면 분석 서버를 다시 시작해야 반영된다 |
| 시작 화면에 "예시 회사로 보기"가 보이는지, 회사 확정 화면에서 지금 법인에 "저장된 분석 있음"이 붙는지 확인 | 둘 다 없으면 예시 회사 설정을 다시 본다 |
| **경쟁사 비교 자료**: 예시 회사에 저장된 비교 자료(`rivals_deep`)가 있는지 확인한다. 예시 회사에서는 "비교 자료 받기"를 누를 수 없으므로(서버가 막는다) 저장된 자료가 없으면 경쟁사 장면은 비교 대상 정하기만 보인다 | 촬영 중 유료 호출 없이 비교 표를 보이려고 |
| 예시 분석에서 보여 줄 값을 미리 정한다: 재무 "미확보" 사유, 국민연금 12개월, 투자 라운드, 특허, **엇갈림 값 = 설립**(금융위 2022-01-04 / 웹 조사 2020-09, 2026-11-23 확인. 지금 법인은 합병 뒤 이름을 바꾼 존속법인이라 법인 설립일과 창업 시점이 다르다). 회사 분석 맨 위 "지금 확인할 것"의 "엇갈림 값 1개"를 누르면 두 값이 바로 펼쳐진다 | 촬영 중에 찾느라 헤매지 않게 |
| 대조할 공고 1건을 정하고 **촬영 전에 한 번 대조해 둔다** `[확인 필요: 대조할 공고. 스냅샷 기준일(2026-11-21) 뒤 마감된 공고는 목록에서 빠진다]` | 공고문 조건 추출이 서버에 저장돼, 촬영 때는 회사 대조만 돈다 |
| 요약할 운용사 1곳을 정한다(이미 투자함이 아닌 곳) | 요약 결과가 비면 다른 곳으로 바꾼다 |
| **비용 확인**: 촬영(리허설 포함)에서 공고문 대조와 운용사 요약을 몇 번 부를지 정하고 Liner 잔액을 확인 | 예시 회사여도 대조·요약은 막지 않고 실제 비용이 든다. 대조는 2026-11-21 실측 약 $0.05(처음 추출이면 $0.02~0.09 추가), 운용사 요약은 비용을 재지 않았다 |
| 브라우저 창 1280×800 안팎, 확대 100%, 즐겨찾기 막대 숨김. 담은 항목이 없는 새 브라우저 프로필 | 담은 항목·노트는 브라우저에 저장된다. 리허설 흔적을 남기지 않게 |
| 주소창에 회사 id(법인등록번호)가 찍혀도 되는지 정한다 `[확인 필요]` | 법인등록번호는 공개 정보지만, 저장소에는 적지 않기로 했다 |

기다리는 구간(자격 대조, 운용사 요약)은 **편집으로 줄이되 화면에 실제 걸린 시간을 자막으로 넣는다.** 속도를 숨기지 않는다.

새 분석이 단락별로 채워지는 모습은 찍지 않는다. 새 분석은 한 번 시작하면 끝까지 돌고, 기준 기업 실측으로 약 3분, Liner 19회, 약 $0.26가 든다. 넣고 싶으면 따로 찍고 자막에 "실제 분석, 약 3분"을 쓴다.

## 장면

### 1. 문제 (0:00~0:20)
- **화면**: 기업마당 공고 목록, 공고문 PDF 47쪽을 넘기는 모습(정지 화면 두 장이어도 된다).
- **말**: "자금을 준비하는 회사는 먼저 우리 회사를 정리해야 합니다. 재무, 고용, 투자, 특허가 기관마다 흩어져 있고, 자료끼리 다르기도 합니다. 그 값으로 천삼백 건이 넘는 공고 중 맞는 것을 찾고, 47쪽 공고문을 읽어야 합니다."
- **자막**: 접수 가능 공고 1,303건(기업마당, 2026-11-21)

### 2. 시작과 회사 확정 (0:20~0:40)
- **화면**: 성장노트 시작 화면. "기준 기업"을 넣고 "분석 시작". 회사 확정 화면에 "기준 기업" 법인 둘이 나온다. 대표와 시군구가 같아, 이름이 같은 후보에만 사업자번호·건물까지 나온 주소·이전 이름이 더 붙는다(지금 법인에 "이전 이름 … · 2024-12 변경"). 지금 법인(저장된 분석 있음)을 고르고 **"저장된 분석 보기"**.
- **말**: "회사 이름을 넣으면 금융위원회 자료에서 법인을 찾습니다. 같은 이름의 법인이 둘인데, 대표도 지역도 같습니다. 그래서 사업자번호와 이전 이름까지 보여 줘 고르게 합니다. 성장노트는 고른 법인의 자료만 쓰고, 다른 법인 자료를 섞지 않습니다."
- **주의**: 저장된 분석이 있는 법인은 "저장된 분석 보기"라 새 분석이 시작되지 않는다. 버튼 글이 "이 회사로 분석"이면 누르지 말고, 시작 화면의 "예시 회사로 보기"로 들어간다.

### 3. 회사 분석 (0:40~1:35)
- **화면**: 회사 표시줄(이름·지역·업력·"예시 회사"·분석 시각). 핵심 값 4칸(매출, 국민연금 가입자, 누적 투자, 검색으로 확인한 특허). 목차로 재무·고용 → 투자 → 기술을 차례로 비춘다.
  - 재무·고용: 재무는 "미확보"와 사유, 국민연금 가입자 12개월 선 그래프와 "참고".
  - 투자: 라운드와 투자기관.
  - 기술: 검색으로 확인한 특허(출원인 확인). 전체 보유 수가 아니라 검색으로 찾아 출원인을 원문에서 확인한 건수다.
- **말**: "회사 분석은 공식 자료, 개요, 투자, 뉴스, 특허를 단락별로 채웁니다. 실제 분석은 약 3분, Liner 호출 19번이 들었고, 영상에서는 저장해 둔 분석을 엽니다. 이 법인에는 금융위원회 재무 자료가 없어 매출을 만들지 않고 '미확보'로 둡니다. 국민연금 가입자 수는 직원 수와 다르기 때문에 '참고'로 표시합니다."
- **자막**: 저장된 분석({분석 날짜}) · 실제 분석 약 178초, Liner 19회

### 4. 엇갈림과 출처 (1:35~2:00)
- **화면**: 핵심 값 아래 **"지금 확인할 것"**(엇갈림 값 1개, 미확보 값 2개)을 비추고 "엇갈림 값 1개"를 누른다. 설립 두 값(금융위 2022-01-04 / 웹 조사 2020-09)이 펼쳐지면 "개요 단락에서 보기"로 넘어가 값 하나를 눌러 출처를 연다(기관·자료 이름, 자료 종류, 기준일).
- **말**: "값마다 얼마나 확인됐는지와 어디서 왔는지를 따로 붙입니다. 자료끼리 값이 다르면 하나를 고르지 않고 '엇갈림'으로 둘 다 보여 줍니다. 엇갈린 값과 모르는 값은 맨 위 '지금 확인할 것'에 모아, 무엇부터 확인할지 바로 보이게 했습니다."
- **주의**: 저장된 예시 분석의 설립 엇갈림을 쓴다. 다른 회사로 찍으면 엇갈림 값이 없을 수 있다. 그때는 출처 열기만 보여 주고 둘째 문장을 뺀다.

### 5. 경쟁사 분석 (2:00~2:25)
- **화면**: 메뉴 "경쟁사 분석". 맨 위 **나란히 비교**와 그 아래 접힌 줄 "비교 대상 4곳: … · 비교 대상 변경"(저장된 비교 자료의 경쟁사가 비교 대상으로 채워져 있다. 눌러 펼치면 경쟁사 후보마다 "포함 / 제외"). 표를 비춘다: 우리 회사 첫 열, 줄은 매출·국민연금 가입자·누적 투자·검색으로 확인한 특허·최근 라운드·주요 투자자·설립. 재무가 없는 경쟁사 칸의 "미확보"와 사유를 확대. 표 바로 아래 "항목별 한계"를 펼쳐 잠깐 비춘다(특허 줄: 전체 보유 수가 아님). 경쟁사 한 곳의 "사업과 최근 변화"를 펼치고, "경쟁사에 투자한 곳"을 잠깐 비춘다.
- **말**: "심사역은 회사 다음으로 경쟁사를 봅니다. 회사 분석이 찾은 경쟁사 후보 가운데 비교 대상을 정하면, 같은 공공 자료와 투자 자료로 우리 회사와 같은 항목을 나란히 놓습니다. 칸마다 기준 연도와 출처를 붙이고, 누가 낫다는 점수나 순위는 만들지 않습니다."
- **자막**: 비교 자료는 누를 때만(경쟁사 5곳 기준 Liner 약 34회) · 영상은 저장된 자료
- **주의**: 예시 회사에서는 "비교 자료 받기"가 막혀 있다(안내 문장이 보인다). 저장된 비교 자료가 없으면 표에 우리 회사 열만 보이므로, 그때는 비교 대상 정하기까지만 찍고 자막에서 "비교 자료"를 뺀다.

### 6. 자금·판로 (2:25~2:55)
- **화면**: 메뉴 "자금·판로". 맨 위 "기업 유형을 골라 주세요"와 옆의 "창업·벤처기업으로 보입니다(추정)"를 비추고 **"창업·벤처기업"을 직접 누른다.** 빌리는 돈 / 투자받는 돈 목록이 나온다. "이미 투자함" 묶음을 비춘다. 공고 1건과 운용사 1곳을 "담기". 아래로 내려 **판로** 단: 회사 기술 낱말로 찾은 나라장터 입찰공고 목록, 그 아래 판로 지원사업(내수·수출).
- **말**: "자금·판로 조건은 회사 분석 값으로 채웁니다. 다만 기업 유형은 공공 자료에 근거가 없어 자동으로 넣지 않고, 한 번 고르게 합니다. 이미 투자한 운용사는 신규 후보와 따로 묶습니다. 같은 화면의 판로 갈래에서는 회사 기술 낱말로 나라장터 입찰공고를 찾고, 판로 지원사업을 같은 조건으로 거릅니다."
- **자막**: 나라장터 최근 28일 · 무료 조회

### 7. 심사 준비 (2:55~3:55) — 영상의 중심, 실제 비용 발생
- **화면(정책자금·지원사업)**: 담은 공고에서 **"공고문으로 자격 대조"**. 진행 표시를 2~3초 보이고 결과로 넘어간다. 조건별 충족 / 미충족 / 확인 필요, 조건 아래 **공고문 근거 문장**을 확대, "기관에 물어볼 것", "부족한 요건".
- **말**: "담은 공고는 공고문을 읽어 우리 회사 값과 조건마다 견줍니다. 근거 문장은 모델이 쓴 글을 그대로 믿지 않고, 공고문에 글자 그대로 있는 것만 남깁니다. 회사 값에 없는 것은 추측하지 않고 '확인 필요'로 두고, 기관에 무엇을 물을지 정리합니다. 선정 확률이나 점수는 만들지 않습니다."
- **자막**: 실제 약 {n}초 · 조건 추출 `openai/gpt-6.2-sol` · 대조 `anthropic/claude-opus-5.5` · Liner 게이트웨이 · 실제 호출
- **화면(투자)**: 갈래 "투자". 담은 운용사에서 **"운용사 요약"**. 확인된 사실, 맞닿는 점, 물어볼 것. 이어서 "미팅 근거 묶음"과 "투자 미팅 예상 질문"을 잠깐 비춘다.
- **말**: "운용사는 대신 검색해, 검색 결과에 실제로 적힌 사실만 정리합니다. 미팅 근거 묶음은 회사 분석에서 이미 받은 결과만 모아 새로 조회하지 않습니다."
- **자막**: 실제 약 {n}초 · Liner 검색 1회 + 모델 1회 · 실제 호출

## 촬영 중 문제가 생기면

| 상황 | 대응 |
|---|---|
| 자격 대조가 실패하거나 1분 넘게 걸린다 | 다시 누른다(조건 추출은 저장돼 있어 대조만 다시 돈다). 계속 실패하면 준비 때 대조한 화면을 따로 찍어 둔 것으로 바꾸고 자막에 "사전 촬영"을 쓴다 |
| 대조 결과가 준비 때와 다르다 | 대조는 실행마다 문장이 조금 달라진다. 판정이 같으면 그대로 쓴다 |
| 운용사 요약에 확인된 사실이 없다 | 다른 운용사로 다시 한다. 검색 결과에 근거가 없으면 비워 두는 것이 정상 동작이다 |
| "오늘 호출 상한에 닿아…"가 나온다 | 하루 상한은 한국 시간 0시에 다시 센다. 서버를 다시 시작해도 풀리지 않는다. 꼭 필요하면 `GROWTH_DAILY_LIMIT_<API>`로 올리고 서버를 다시 시작한다 |
| "요청이 잠시 많았습니다…"가 나온다 | 접속 주소별 분당 6회 제한이다. 1분 기다린다 |
| "분석 서버와 연결이 끊겼습니다"가 나온다 | `scripts/run_local.sh`를 다시 실행하고 화면을 새로 고친다 |
| "예시 회사로 보기"가 안 보인다 | `GROWTH_EXAMPLE_COMPANY_ID` 값, 그 회사 분석이 끝까지 끝났는지 확인하고 분석 서버를 다시 시작한다 |

## 말하지 않을 것

- 줄어드는 시간이나 비용의 수치. 잰 적이 없다.
- 선정 가능성, 투자 가능성. 서비스가 판단하지 않는다.
- "모든 공고", "정확하다", "모든 자료를 모은다" 같은 표현. 목록은 공공 API가 주는 범위이고, 세부 자격은 대조한 공고만 확인되며, 특허·논문은 검색으로 확인된 범위다.
