## 0. 검사 방법과 가짜 응답

**확인 방법**

- **자동**: `npm test`(부품·규칙 단위 시험)나 브라우저 자동 점검(`web/scripts/ux-check.mjs`, 설치된 Chrome을 조작)으로 판정한다. 서버는 가짜 응답으로 바꾼다. 실제 유료 호출은 하지 않는다.
- **화면**: 사람이 화면을 보고 판정한다(인쇄 쪽수, 움직임, 읽기 쉬움처럼 자동으로 가르기 어려운 것).
- **폭**: 390×844(휴대폰), 820×1180(iPad 세로), 1180×820(iPad 가로), 1280×800(PC). "모든 폭"은 이 넷이다.
- **요청 세기**: "요청 n회"는 가짜 서버가 받은 해당 주소의 요청 수다.

**가짜 응답(테스트 담당이 만든다, 실제 기업 데이터를 넣지 않는다)**
