# 정보 구조와 사용 흐름

> 2026-11-22. 기준: `docs/integration-design.md` 2절(흐름·주소), 4.3절(저장), 6.5절(실측), 10.2절(사례 화면). 화면 하나하나의 내용은 `screens.md`.
> 2026-11-23 화면 구조 개편: 상단 메뉴를 회사 분석 · 경쟁사 분석 · 자금·판로 · 심사 준비 · 노트로 바꿨다. 경쟁사는 회사 분석 단락에서 새 화면 `/c/[id]/rivals`로, 판로는 자금·판로의 셋째 갈래(`?lane=sales`)로 옮겼다(`screens.md` 4B절·5.2절).

## 1. 정보 구조

### 1.1 화면과 주소

| 주소 | 화면 | 회사 표시줄 | 단계 메뉴 | 지금 코드와의 관계 |
|---|---|---|---|---|
| `/` | 시작 | 없음 | 없음 | 지금 자금 찾기 첫 화면을 바꾼다 |
| `/?name={이름}` | 회사 확정 | 없음 | 없음 | 새로. 주소에 이름을 넣어 뒤로 가기가 자연스럽게 되게 한다(제안 6) |
| `/c/[id]` | 회사 분석 | 있음 | 있음 | 새로 |
| `/c/[id]/rivals` | 경쟁사 분석 | 있음 | 있음 | 2026-11-23 새로. 회사 분석의 경쟁사 단락(후보 고르기)과 경쟁사 깊이 비교 결과를 옮겨 다시 짰다. 새 서버 수집 없음 |
| `/c/[id]/funding` | 자금·판로(갈래: 빌리는 돈, 투자받는 돈, 판로) | 있음 | 있음 | `Finder`를 옮긴다. 판로 갈래는 옛 판로 화면을 옮겼다 |
| `/c/[id]/review` | 심사 준비 | 있음 | 있음 | `NoticeCheck`, `GpBrief`, `RivalCompare`를 모은다 |
| `/c/[id]/sales` | (옛 판로) | — | — | `/c/[id]/funding?lane=sales`로 보낸다(2026-11-23) |
| `/c/[id]/note` | 노트 | 있음 | 있음 | 사례 화면 상담 메모(`Workspace`의 `Memo`) 부품을 실제 데이터로 |
| `/funding` | 회사 없이 자금 둘러보기 | 없음 | 없음 | 지금 자금 찾기에서 유료 기능을 뺀 것(제안 3) |
| `/cases`, `/s/[id]` | (없앰) | — | — | 가상 데이터가 있어 `/`로 보낸다(제안 9) |

**주소 안의 상태**

- 회사 분석 단락: `#overview`, `#finance`, `#investment`, `#news`, `#tech`. 옛 `#rivals`는 경쟁사 분석(`/c/[id]/rivals`)으로 보낸다.
- 자금·판로 갈래: `?lane=debt`(빌리는 돈, 기본) / `?lane=invest`(투자받는 돈) / `?lane=sales`(판로). 넓은 화면에서는 빌리는 돈·투자받는 돈이 나란히, 판로가 그 아래 단으로 함께 보이므로 갈래 값은 중간·좁은 화면의 탭에 쓰고, 넓은 화면에서 `?lane=sales`로 열면 판로 단으로 스크롤한다.
- 심사 준비 갈래: `?tab=grants`(정책자금·지원사업) / `?tab=invest`(투자). 미팅 근거 묶음은 `?tab=invest#evidence`.
- 자금·판로 조건(지역·기업 유형·필요한 지원·관심 분야)은 사용자가 바꿨을 때만 주소에 남긴다(지금 `Finder` 방식). 바꾸지 않았으면 회사 값을 쓴다.
- 펼침 상태는 주소에 남기지 않는다.

### 1.2 메뉴

- 회사가 없는 화면: 머리줄에 "성장노트"만. `/funding`에는 "회사 분석 시작" 링크를 더한다.
- 회사가 정해진 화면: 단계 메뉴 "회사 분석", "경쟁사 분석", "자금·판로", "심사 준비", "노트"(좁은 화면은 짧은 이름 "회사", "경쟁사", "자금·판로", "심사", "노트"). 처음에는 이 순서로 안내하고, 회사가 확정된 뒤에는 어느 단계든 바로 간다(설계 문서 2절).
- 사례 화면은 메뉴에 없다(설계 문서 10.2).

**단계 메뉴를 누를 수 있는 때**

| 단계 | 누를 수 있는 때 | 그 전에 열면(주소로) |
|---|---|---|
| 회사 분석 | 언제나 | — |
| 경쟁사 분석 | 언제나 | `profile` 전이면 후보 자리에 "회사 분석에서 경쟁사 후보를 찾고 있습니다" |
| 자금·판로 | `official`이 끝났을 때(완료·미확보 모두). 실측 약 10초 | "회사 값을 받는 중입니다. 조건을 직접 골라도 됩니다." |
| 심사 준비 | 언제나 | 담은 항목이 없으면 빈 상태 문구 |
| 노트 | 언제나 | 빈 칸은 "확인 중" |

## 2. 주요 사용 흐름

### 흐름 1. 처음 쓰는 대표 — 회사 이름에서 노트 인쇄까지

**사람**: 자금 조달을 준비하는 중소·벤처기업 대표. iPad 가로로 연다. 처음 온다.
**목표**: 우리 회사가 받을 수 있는 정책자금을 찾고, 담당 기관에 무엇을 물을지 정리해 상담에 가져간다.

| # | 화면 | 사용자가 보는 것 | 사용자가 하는 것 | 다음 |
|---|---|---|---|---|
| 1 | 시작 | 제목, 회사 이름 입력, 시간 안내 한 줄 | 회사 이름을 넣고 "분석 시작" | 1~2초 "법인 찾는 중" |
| 2 | 회사 확정 | 같은 이름 법인 2곳(대표·설립·본사) | 우리 회사를 골라 "이 회사로 분석" | 회사 분석 |
| 3 | 회사 분석, 0초 | 회사 이름, 진행 줄, 핵심 값 4칸과 단락 6개가 "확인 중" 자리 표시 | 기다리거나 스크롤 | |
| 4 | 약 10초 | 표시줄에 지역·업력, 핵심 값 매출·국민연금 가입자, 재무·고용 차트 2개, 개요의 대표·설립·본사. 단계 메뉴 "자금·판로"이 열림 | 재무 차트를 본다 | |
| 5 | 약 22초 | 개요의 사업 설명·제품·핵심 기술. 기술 단락 아래 "경쟁사 후보 3곳, 비교 대상 0곳" | "경쟁사 분석에서 보기" → 후보 2곳 "포함", 1곳 "제외" → 단계 메뉴 "회사 분석"으로 돌아온다(분석은 계속) | 경쟁사 분석 |
| 6 | 약 30~40초 | 투자(최근 라운드 3건), 기술(특허 연도 선, 주요 특허 3건), 최근 동향(중요 사건 3개) | "자금·판로 보기" | 자금·판로(분석은 계속) |
| 7 | 자금·판로 | 조건 칩이 회사 값으로 채워짐(서울, 융자·보증, AI·딥테크·소프트웨어). 기업 유형은 근거가 없어 맨 위에 "기업 유형을 골라 주세요"와 "창업·벤처기업으로 보입니다(추정)" | "창업·벤처기업"을 한 번 누른다 → 빌리는 돈 카드 5장. 카드 2장 "담기" | 담은 항목 막대 "담은 항목 2개" |
| 8 | 약 3분(다른 화면에 있는 동안) | 회사 분석 메뉴의 진행 표시가 사라짐. 투자기관이 원문 확인으로 바뀌고, 투자받는 돈의 "이미 투자한 운용사"가 채워짐 | "심사 준비로 가기" | 심사 준비 |
| 9 | 심사 준비, 정책자금·지원사업 | 담은 공고 2건(대조 전), "대조에 쓰는 회사 값 5/8개 채움" | "회사 정보 수정"에서 필요한 자금, 그 밖의 사항(인증, 체납 없음)을 넣고 저장 | |
| 10 | | | 첫 공고 "공고문으로 자격 대조"(30~50초), 기다리는 동안 둘째 공고도 대조 | |
| 11 | | 공고마다 "확인 후 판단", "충족 4", "미충족 1", "확인 필요 2". 부족한 요건 "미충족 1개, 확인 필요 3개" | 부족한 요건을 펼쳐 근거 문장을 본다. "경쟁사 조건이라면?"을 펼쳐 대조 | |
| 12 | 노트 | 회사 정보(상태·출처), 담은 공고와 대조 결과, 다음 할 일(기관에 물을 질문) | 메모를 쓰고 "인쇄·PDF 저장" | A4 1~2쪽 |

**갈림길**

- 2에서 후보가 1곳이고 이름이 같으면 회사 확정을 건너뛴다.
- 2에서 "목록에 없음"을 고르고 "공개 자료만으로 분석"을 누르면(후보 0곳 화면의 단추와 같은 말) 재무·고용 단락이 미확보("법인이 확인되지 않아…")로 끝나고, 자금·판로는 바로 열리며 조건을 직접 고른다. 약 3분 뒤 `facts`가 본사 지역을 주면 "조건을 바꿀까요?"를 묻는다.
- 4~8 사이에 단락 하나가 상한에 닿으면 그 단락만 "미확보: 오늘 호출 상한에 닿아…"로 끝나고 나머지는 계속 채워진다.
- 3~8 동안 창을 닫았다가 다시 열면 진행 중 작업을 찾아 이어 받는다(서버가 다시 시작되지 않았다면).

### 흐름 2. 다시 들어온 사용자 — 저장된 분석 이어 보기

**사람**: 흐름 1의 대표가 일주일 뒤(또는 45일 뒤) 같은 iPad로 다시 온다.

| # | 화면 | 보는 것 | 하는 것 |
|---|---|---|---|
| 1 | 시작 | "이어서 보기"에 그 회사 한 줄: 이름, "2026-11-22 20:44 분석", "담은 항목 2개" | 줄을 누른다 |
| 2 | 회사 분석 | 브라우저 사본을 곧바로 보여 준다. 진행 줄 없음. 표시줄에 "2026-11-22 20:44 분석". 고친 값은 "직접 입력" | 그대로 둘러본다 |
| 3 | 심사 준비 | 지난번 대조 결과가 그대로. 회사 값을 바꾼 적이 있으면 "이전 회사 값으로 한 대조입니다" | 필요하면 "다시 대조" |

**45일 뒤라면**: 2에서 표시줄에 "2026-10-08 분석, 오래된 분석입니다"와 한 줄 "45일 전 분석입니다. 최근 자료를 보려면 새로 분석하세요." 자동으로 다시 분석하지 않는다.

- "새로 분석" → 확인 창(3분 안팎, Liner 약 19회, 지금 분석은 남김, 고친 값·담은 항목·노트는 그대로) → "새로 분석"을 누르면 지금 결과를 둔 채 단락마다 "새로 확인 중"이 붙고, 새 결과가 오는 대로 단락이 바뀐다.
- 뉴스만 보고 싶으면 최근 동향의 "뉴스만 새로 받기"(20초 안팎, Liner 약 3회).

**다른 사람이 같은 회사를 열 때**(같은 주소를 받은 팀원, 다른 브라우저): 브라우저 사본이 없으므로 서버의 최근 저장된 분석을 받아 보여 준다. 분석 시각을 붙인다. 고친 값·담은 항목·노트는 보이지 않는다(그 사람의 브라우저에 없다).

**브라우저 저장소가 지워졌을 때**: 이어서 보기가 비어 있다. 회사 이름을 다시 넣으면 회사 확정에 "저장된 분석 있음"이 붙고, "저장된 분석 보기"로 곧바로 연다. 고친 값과 노트는 사라졌으므로 노트의 "파일에서 불러오기"로 되살린다.

### 흐름 3. 예시 회사로 둘러보기

**사람**: 해커톤 심사위원이나 처음 온 사람. 자기 회사를 넣지 않고 무엇을 하는 서비스인지 보고 싶다. 휴대폰 세로.

| # | 화면 | 보는 것 | 하는 것 |
|---|---|---|---|
| 1 | 시작 | "예시 회사로 보기" | 누른다 |
| 2 | 회사 분석 | 서버에 저장된 예시 회사 분석이 곧바로 모두 채워져 있다. 이름 옆 "예시 회사", "새로 분석" 단추 없음, 한 줄 "저장해 둔 예시 분석입니다. 우리 회사를 보려면 회사 이름을 넣으세요." | 단락 목차 칩으로 "최근 동향"에 가서 "기사 {n}건 보기"를 연다 |
| 3 | | 분류 칩과 기사 20건 | "투자유치" 칩을 고른다 |
| 4 | 자금·판로 | 예시 회사 값으로 채운 조건, 이미 투자한 운용사 묶음 | 공고 하나를 "담기" |
| 5 | 심사 준비 | 담은 공고 1건 | "공고문으로 자격 대조"(유료지만 사용자가 눌렀을 때만) |
| 6 | 노트 | 예시 회사 노트 | 시작으로 돌아가 자기 회사 이름을 넣는다 |

- 예시 회사에서도 고친 값과 담은 항목은 그 브라우저에만 저장된다. 서버의 예시 분석은 바뀌지 않는다.
- 예시 분석 파일이 서버에 없으면 시작 화면에 "예시 회사로 보기"가 없다.
- 화면 어디에도 "시제품", "가상 데이터" 같은 말이 없다. 예시 회사는 실제 분석이다.

### 흐름 4. 회사 없이 자금만 둘러보기

**사람**: 여러 회사를 돕는 지원기관 담당자. 특정 회사 없이 이번 달 공고를 훑는다. PC.

| # | 화면 | 보는 것 | 하는 것 |
|---|---|---|---|
| 1 | 시작 | "회사 없이 자금만 둘러보기" | 누른다 |
| 2 | 자금 둘러보기(`/funding`) | 지금 펀딩노트의 문장형 조건("{지역}에 있는 {기업 유형}입니다…"), 위에 안내 띠 "회사 이름을 넣으면 조건을 채우고, 공고문 자격 대조까지 이어집니다." | 지역과 필요한 지원을 바꾸고, 공고 3건 "저장" |
| 3 | | 저장한 항목 3건 | "목록 복사해서 공유" → 메신저에 붙인다 |
| 4 | | 조건이 담긴 주소 | 동료에게 보낸다. 동료가 열면 같은 조건이 그대로 |

- 여기서는 유료 호출이 없다. 자격 대조를 하려면 "회사 분석 시작"으로 간다.
- `/funding`에서 저장한 항목은 회사 분석의 담은 항목과 섞이지 않는다.

### 흐름 5. 심사역 — 경쟁사와 나란히 보기 (2026-11-23)

**사람**: 투자 미팅을 앞둔 VC 심사역. 회사 분석 다음으로 같은 시장의 국내 경쟁사를 본다. iPad 가로.

| # | 화면 | 보는 것 | 하는 것 |
|---|---|---|---|
| 1 | 회사 분석 | 핵심 값 4칸, 단락 5개, 기술 단락 아래 "경쟁사 후보 4곳, 비교 대상 0곳" | 단계 메뉴 "경쟁사 분석" |
| 2 | 경쟁사 분석 | "비교 대상 정하기": 후보 4곳(관계·이유·상태), "나란히 비교"에는 우리 회사 열만 | 2곳 "포함", 1곳 "제외". 목록에 없는 회사 1곳을 "경쟁사 직접 추가"(바로 비교 대상에 포함). 비교 대상은 최대 5곳이고, 다 차면 남은 "포함"과 직접 추가가 막힌다 |
| 3 | | 비용 줄 "Liner 약 22회 (비교 대상 3곳 기준, 한 곳당 약 6회)" | "비교 자료 받기"(유료, 누를 때만) |
| 4 | | "비교 자료를 받고 있습니다 (…)". 다른 화면에 다녀와도 계속 | 기다리거나 다른 단계를 본다 |
| 5 | | 비교 표: 매출·국민연금 가입자·누적 투자·검색으로 확인한 특허·최근 라운드·주요 투자자·설립을 회사마다 한 열로. 칸마다 기준, 상태 낱말, 짧은 출처. 표 바로 아래 "항목별 한계"(접힘)에서 숫자의 한계를 읽는다. 재무가 없는 경쟁사 칸은 "미확보"와 사유 | 경쟁사별 펼치기 줄을 열어 사업·제품·최근 변화를 읽는다 |
| 6 | | "경쟁사에 투자한 곳": 경쟁사마다 투자기관, "모태펀드 운용사" 표시 | "투자받는 돈에서 보기" |
| 7 | 자금·판로 `?lane=invest` | 경쟁사에 투자한 운용사 카드에 "경쟁사에 투자"와 "{경쟁사}에 투자한 곳입니다." | 미팅에서 물을 곳을 담는다 |

- 점수·순위·"우세" 같은 판정은 어디에도 없다. 같은 항목을 같은 기준으로 나란히 둘 뿐이다.
- 예시 회사에서는 3을 누를 수 없고("예시 회사는 비교 자료를 새로 받을 수 없습니다…"), 서버에 저장된 비교 자료가 있으면 5~6이 곧바로 보이고 "나란히 비교"가 맨 위에 온다. 비교 대상은 그 자료가 비교한 곳으로 채워져 "비교 대상 n곳: …" 한 줄로 접혀 있다(screens 4B.1 "처음 비교 대상").

## 3. 단계 사이 이동

| 어디서 | 무엇을 누르면 | 어디로 |
|---|---|---|
| 어느 화면이든 | 단계 메뉴 | 그 단계 |
| 어느 화면이든 | "성장노트" | 시작 |
| 회사 분석 핵심 값 칸 | 칸 전체 | 같은 화면의 그 단락 |
| 회사 분석 | "자금·판로 보기" | 자금·판로 |
| 투자 단락 바닥 | "운용사 목록 보기" | 자금·판로 `?lane=invest` |
| 최근 동향 단락 바닥 | "미팅 근거 묶음 보기" | 심사 준비 `?tab=invest#evidence` |
| 기술 단락 바닥 | "심사 준비 보기" | 심사 준비 |
| 개요 2층 | "다른 법인으로 바꾸기" | 회사 확정(같은 이름으로) |
| 회사 분석 끝 | "경쟁사 분석 보기"(주 단추) | 경쟁사 분석 |
| 자금·판로 투자받는 돈 | "경쟁사 분석으로 가기"(비교 자료 전) | 경쟁사 분석 |
| 경쟁사 분석 경쟁사에 투자한 곳 | "투자받는 돈에서 보기" | 자금·판로 `?lane=invest` |
| 경쟁사 분석 끝 | "자금·판로 보기"(주 단추) | 자금·판로 |
| 자금·판로(판로 갈래 포함) | "심사 준비로 가기"(담은 항목 막대) | 심사 준비(담은 종류에 맞는 갈래) |
| 심사 준비 | "자금·판로에서 고르기", "운용사 고르기" | 자금·판로(해당 갈래) |
| 심사 준비 경쟁사 조건이라면? | "비교 대상 정하러 가기" | 경쟁사 분석 |
| 심사 준비 미팅 예상 질문 "비교 대상 경쟁사 {k}곳" | 관련 자료 링크 | 경쟁사 분석 |
| 옛 주소 `/c/[id]/sales`, `/c/[id]#rivals` | 주소로 열기 | 자금·판로 `?lane=sales`, 경쟁사 분석 |
| 노트 | "자금·판로로 가기"(빈 상태) | 자금·판로 |
| 예시 회사 표시줄 | "회사 이름 넣기" | 시작 |
| `/funding` | "회사 분석 시작" | 시작 |

**지키는 것**

- 단계를 옮겨도 회사 분석 작업은 서버에서 계속된다. 돌아오면 그사이 끝난 단락이 채워져 있다.
- 단계를 옮겨도 진행 중인 대조·요약은 계속되고, 돌아오면 결과가 있다(지금 펀딩노트의 공용 작업 저장소 방식).
- 브라우저 뒤로 가기는 단계 이동을 하나씩 되돌린다. 펼침과 단락 스크롤은 기록에 쌓지 않는다.
- 다른 회사로 바꾸려면 시작으로 간다. 회사 두 곳을 한 화면에서 섞어 보이지 않는다.

## 4. 회사 표시줄

모든 회사 화면의 맨 위(머리줄 아래)에 있고 스크롤하면 사라진다. 자세한 문구와 배치는 `screens.md` 1.2절.

| 칸 | 내용 | 누르면 |
|---|---|---|
| 회사 이름 | 회사 분석에서는 화면 제목 | — |
| 지역 칩 | "서울" | 값, 상태, 출처 |
| 업력 칩 | "업력 4년"(설립일로 계산) | 설립일 값, 상태, 출처(엇갈림이면 두 값) |
| 기업 유형 칩 | "창업·벤처기업" 또는 "기업 유형 미확보" | 값과 근거, 미확보면 회사 정보 수정 창 |
| 분석 시각 | "2026-11-22 20:44 분석" / "분석 중 (1분 12초)" / "…, 오래된 분석입니다" | — |
| "회사 정보 수정" | | 회사 정보 수정 창 |
| "새로 분석" | 예시 회사에서는 없음 | 새로 분석 확인 창 |

- 업종, 매출 같은 값은 표시줄에 넣지 않는다. 표시줄은 "지금 어느 회사인가"만 알리고, 값은 회사 분석에 있다.
- 핵심 값 줄은 표시줄의 값(지역, 업력, 기업 유형)을 다시 싣지 않는다.
