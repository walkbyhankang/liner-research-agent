# 성장노트 시각 계획 (디자인 1단계, `frontend-design`)

> 2026-11-22. 바탕: `design-brief.md`(브리프), `screens.md`(구조·문구), 사용자 지시(흰 바탕, 전문 정보 사이트, 압축 후 펼치기, iPad 터치). 2단계(`impeccable`)는 이 계획과 구현 결과를 함께 본다.
> 순서: 1절 첫 계획 → 2절 브리프와 대조해 고친 것 → 3절 고친 뒤 최종 토큰(구현은 3절을 따른다).

## 0. 주제 정하기

- **무엇**: 회사 이름 하나로 공공 자료·공개 보도를 모아 회사를 보여 주고, 자금·심사 준비·판로로 잇는 서비스.
- **누구**: 중소·벤처기업 대표와 재무 담당, 지원기관 담당자, 심사역. iPad 가로·세로, PC, 휴대폰.
- **화면의 주된 일**: 숫자와 그 기준(사업연도, 연결·별도, 월, 통화)을 믿을 수 있게 보이고, 확인하지 못한 것은 못 했다고 쓰는 것.
- **이 세계의 말과 물건**: 감사보고서·재무제표(굵은 윗줄과 가는 아랫줄의 표, 숫자 오른쪽 정렬, "(단위: 억원)"), 통계 자료집(표·그림 아래 출처 한 줄), 회계 장부 용지(녹색 괘선), 공문서 서명에 쓰는 청흑 잉크, 각주 구분선.

## 1. 첫 계획

**색**

| 이름 | hex | 역할 |
|---|---|---|
| 바탕 | `#FFFFFF` | 모든 바탕 |
| 글 | `#1A1F29` | 본문·숫자 |
| 보조 글 | `#667085` | 꼬리표·출처 |
| 선 | `#E4E7EC` | 구분선 |
| 강조 | `#2563EB` | 링크·주 단추 |
| 주의 | `#D97706` | 엇갈림·미확보 |

**글꼴**: Pretendard 하나(본문·제목). 숫자는 `tabular-nums`.

**배치**: 위 머리줄 → 회사 표시줄 → 핵심 값 네 칸(둥근 카드 넷, 큰 숫자와 작은 이름표) → 단락마다 둥근 카드 하나. 넓은 화면은 왼쪽 목차.

**원칙**: 깔끔하게, 카드로 나누기, 상태는 색깔 알약.

## 2. 브리프와 대조해 고친 것

첫 계획을 "비슷한 서비스라면 누구에게나 냈을 안"인지 하나씩 따졌다. 대부분 그랬다.

| # | 첫 계획 | 무엇이 기본값인가 | 고친 것과 이유 |
|---|---|---|---|
| 1 | 글 `#1A1F29` | 검정 대신 쓰는 옅게 물든 거의 검정(브리프 8절) | **청흑 잉크 `#1E2A3F`**. 공문서 서명·재무 서류에 쓰는 파란빛 검정 잉크에서 왔다. 검정을 흉내 낸 회색이 아니라 분명히 남색 쪽이고, 흰 바탕 대비 14:1 |
| 2 | 강조 `#2563EB` | 어느 화면에나 쓰는 파란 단추 | **장부 녹색 `#0C6B58`**. 회계 장부 용지의 녹색 괘선에서 왔다. 누르는 것(주 단추, 펼치기 꺾쇠, 초점, 고른 탭)에만 쓴다. 숫자·상태에는 쓰지 않는다 |
| 3 | 주의 `#D97706` 하나로 엇갈림·미확보 | 신호등의 노랑. 미확보와 엇갈림이 같은 모양 | **엇갈림만 호박색 칠**(`#FCEFD7` 바탕, `#7A4B00` 글). **미확보는 회색 칠 + 점선 테두리**("비어 있음"을 모양으로). 빨강은 팔레트에 두지 않는다(신호등·실패 느낌 없음) |
| 4 | Pretendard | 한국어 화면에서 가장 먼저 손이 가는 기본 글꼴 | **IBM Plex Sans KR + IBM Plex Sans(라틴·숫자)**. 한 가족이라 섞여도 어색하지 않고, 기술·분석 문서 성격이 있다. 숫자는 Plex Sans의 고정폭 숫자(tnum)로 맞춘다 |
| 5 | 핵심 값을 둥근 카드 넷(큰 숫자 + 작은 이름표) | 브리프 7절이 피하라고 한 바로 그 모양(SaaS 카드, KPI 타일) | **재무제표식 숫자 띠**: 굵은 윗줄(2px 잉크)과 가는 아랫줄 사이 네 칸, 칸 사이 세로 실선. 칸 안은 이름표 → 숫자(단위 붙임) → 기준(사업연도, 연결·별도, 월)이 숫자 바로 밑에 붙고 상태 낱말이 이름표 줄 끝에. 숫자와 기준이 한 덩어리로 읽힌다. **화면에서 힘을 주는 곳은 여기 한 곳** |
| 6 | 단락마다 둥근 카드 | 모든 것을 같은 카드로 자르기 | 단락은 **카드 없이 여백과 윗선 하나**로 나눈다. 카드는 정말 한 덩어리인 것(공고·운용사 카드)에만, 그림자 없이 |
| 7 | 단락 제목(큰 글) 아래 요약(작은 글) | 제목이 가장 크고 요약은 회색 | 브리프 3절 "한 줄 요약이 단락보다 약하지 않게"에 맞춰 **뒤집는다**: 단락 이름은 16px 굵게(이정표), **한 줄 요약은 21px**(첫인상) |
| 8 | 상태는 색깔 알약 | 색만으로 구분, 모두 같은 크기로 시끄러움 | 상태 낱말 7개를 **모양으로** 나눈다(3.4절). 원문 확인은 테두리 없는 작은 회색 글(가장 조용), 엇갈림·미확보만 칠 |
| 9 | 출처 줄을 "출처: A · B · C" | 가운뎃점 나열 | **각주 구분선 + 두 부분**(screens 1.3 규칙 8): 짧은 선 하나 아래 "{자료 이름} ({종류})"와 작게 "{기준일}, {기준}". 책·보고서의 각주 모양이다 |
| 10 | 차트 막대 색 두 가지 | 흑백 인쇄에서 구분 안 됨 | 매출은 잉크 칠, 영업이익은 빗금, 음수는 기준선 아래 빗금. 이름은 막대 옆에 직접 쓴다 |

## 3. 최종 계획 (구현 기준)

### 3.1 색 (기본 6개 + 쓰임이 정해진 옅은 색)

| 이름 | hex | 역할 |
|---|---|---|
| `paper` 바탕 | `#FFFFFF` | 모든 화면 바탕(인쇄도 같음) |
| `ink` 청흑 잉크 | `#1E2A3F` | 본문, 숫자, 제목, 차트의 우리 회사 |
| `sub` 보조 | `#586377` | 꼬리표, 기준일, 출처, 한계 안내(대비 6:1, 12px 이상만) |
| `rule` 선 | `#DDE2E9` | 구분선, 표 안 가는 선, 카드 테두리 |
| `ledger` 장부 녹색 | `#0C6B58` | 누르는 것: 주 단추, 펼치기 꺾쇠와 열린 줄의 선, 초점 테두리, 고른 탭 밑줄, 담은 항목 막대 |
| `amber` 엇갈림 | `#7A4B00` / 칠 `#FCEFD7` | 엇갈림 낱말과 칠, 판정 "확인 필요" 표시 |

옅은 색(새 색이 아니라 위 색의 쓰임): `wash #F3F5F8`(줄 자세히가 열린 줄, 미확보 칠, 자리 표시), `ledger-soft #E5F1ED`(고른 칩, 담은 항목 막대 바탕). 갈래 표시선(이 두 곳에만): 빌리는 돈 `#8B6534`, 투자받는 돈 `#3A52A0` — 갈래 머리의 3px 윗선과 갈래 탭 밑줄에만 쓰고 카드·글에는 퍼뜨리지 않는다.

### 3.2 글꼴과 크기

- **IBM Plex Sans KR**(한글) + **IBM Plex Sans**(라틴·숫자). 굵기 400·500·600·700. 글꼴을 못 받으면 Apple SD Gothic Neo / Noto Sans KR.
- 숫자는 어디서나 `tabular-nums lining-nums`. 단위(억원, 명, 건)는 숫자에 붙여 한 단계 작게.
- 크기 단계(Bringhurst 전통 단계에서 고름): **12**(출처·기준일·꼬리표, 이보다 작게 쓰지 않음) / **14**(보조 글, 표) / **16**(본문, 단락 이름) / **18**(1층 목록 제목) / **21**(단락 한 줄 요약) / **28**(화면 제목, 좁은 화면 핵심 숫자) / **36**(회사 이름, 넓은 화면 핵심 숫자).
- 본문 줄 간격 1.7(한글은 영문보다 넉넉히), 제목 1.3. `word-break: keep-all`. 한 줄은 한글 40~45자(약 680px)를 넘기지 않는다.
- 대문자 머리말, 고정폭 글꼴, 제목 속 낱말 하나 강조는 쓰지 않는다.

### 3.3 배치

**정렬**: 모두 왼쪽 정렬. 가운데 정렬은 빈 상태 문구에만. 숫자 표의 숫자 열만 오른쪽 정렬.

**머리줄**: "성장노트" 글자표 + 단계 줄. 단계 다섯 개를 가는 선 하나로 잇고(순서가 있는 내용이라 선이 정보다, 번호는 붙이지 않음) 지금 단계에 장부 녹색 3px 밑줄.

### 3.4 작은 부품

**상태 낱말 7개** (눈에 띄는 순서대로, 낱말은 언제나 보인다)

| 낱말 | 모양 |
|---|---|
| 엇갈림 | 호박색 칠, 굵게, 테두리 없음 |
| 미확보 | 회색 칠(`wash`), 굵게, 점선 테두리(`sub`) |
| 추정 | 칠 없음, 파선 테두리, 잉크 글 |
| 보도 | 칠 없음, 실선 테두리, 보조 글 |
| 참고 | 칠 없음, 점 테두리, 보조 글 |
| 직접 입력 | 다른 계열: 테두리 대신 장부 녹색 밑줄과 펜 아이콘 |
| 원문 확인 | 가장 조용: 테두리·칠 없이 보조 글만 |

**판정 낱말**(자격 대조에만, 상태 낱말과 다른 모양): 낱말 앞에 작은 원 — 충족 = 꽉 찬 원(장부 녹색), 미충족 = 빈 원(잉크, "채우면 열리는 요건"), 확인 필요 = 반원(호박색), 판단 대상 아님 = 짧은 선(보조). 칠한 알약이 아니라 글과 표시.

**펼치기 줄**: 가로 전체, 높이 48px, 윗선 1px, 글은 잉크(흐리게 하지 않음), 오른쪽 끝에 장부 녹색 꺾쇠. 열면 꺾쇠가 돌고, 줄과 열린 영역 왼쪽에 장부 녹색 2px 선이 이어져 "이 줄에서 나왔다"를 보인다.

**줄 자세히**: 줄 전체가 단추. 열린 줄은 `wash` 바탕, 아래 내용은 같은 들여쓰기에 왼쪽 2px 보조 선.

**더 보기**: 펼친 영역 끝의 가로 전체 단추, 테두리 1px, "{k}건 더 보기 ({남은 수}건 남음)".

**출처 줄**: 24px 짧은 각주선 → "{자료 이름} ({종류})" 보조 글 → 작게 "{기준일}, {기준}". 원문이 있으면 끝에 "원문 열기"(새 창 아이콘 + 화면 읽기용 "새 창").

**자리 표시**: 움직이지 않는 `wash` 막대. 채워질 내용과 같은 높이(차트 자리는 차트 높이 그대로).

**차트**: 높이 160~180px, 가는 축, 값은 막대·점 옆에 직접. 매출 = 잉크 칠, 영업이익 = 빗금, 음수 = 기준선 아래. 국민연금 선은 세로축이 0이 아니면 축 아래에 "세로축은 {n}명부터". 특허 선은 최근 2년에 빗금 띠 + "공개 전 기간". 여러 회사면 우리 회사만 잉크, 나머지 보조색, 이름은 선·막대 끝에.

### 3.5 원칙

1. **숫자가 주인공이다.** 고정폭 숫자, 단위는 숫자에 붙이고, 기준은 숫자 바로 밑. 숫자와 기준을 떼어 놓지 않는다.
2. **힘은 한 곳에.** 재무제표식 숫자 띠(핵심 값 네 칸)만 굵은 선을 쓴다. 나머지는 여백과 가는 선.
3. **칠은 주의에만.** 엇갈림·미확보·담은 항목 막대 말고는 면을 칠하지 않는다. 그림자, 그라데이션 없음.
4. **접힌 것은 무엇이 몇 건 숨었는지 말한다.** 펼치기 장치는 세 가지 모양뿐이고 화면마다 같다.
5. **움직임은 사용자에게 답할 때만.** 펼침 0.15초, 들어오며 떠오르는 움직임 없음, 자리 표시는 반짝이지 않는다. 움직임 줄이기 설정이면 모두 끈다.
6. **누르는 곳은 44px.** 줄·칩·단추 모두. 마우스 올리기에만 있는 정보는 없다.

### 3.6 스스로 볼 것 (브리프 12절 대응)

- 흰 바탕 하나, 미색 없음. 그림자·그라데이션 없음.
- 3초 안에 숫자 넷과 기준이 읽히는가(숫자 띠).
- 원문 확인은 조용하고, 엇갈림·미확보는 칠로 바로 보이는가.
- 펼치기 줄·더 보기·줄 자세히가 화면마다 같은 모양인가.
- 390px에서 위에 붙은 줄이 둘 이하인가(단계 줄, 단락 목차 줄 또는 갈래 탭).
- 점수판·게이지·신호등·별점·그림 문자가 없는가.
